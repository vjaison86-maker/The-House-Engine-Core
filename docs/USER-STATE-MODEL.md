# User State Model™

## Status

Version: 0.1

Stage: Foundation

---

# Purpose

The User State Model™ defines how The House Engine™ understands a person's current position within their self-discovery journey.

The purpose is not to classify or label people.

The purpose is to understand context so that The Mirror™ can provide more relevant reflection and guidance.

---

# Core Principle

## Understand Before Guiding

The Mirror™ should first understand where a person currently is before suggesting questions, practices, or next steps.

A person's current state influences:

- the questions they need
- the reflections they explore
- the practices that may help
- the journey path available

---

# State Philosophy

A user state represents:

- current awareness
- current understanding
- current relationship with patterns
- readiness for exploration

A user state does not represent:

- personal value
- success or failure
- permanent identity
- a fixed personality type

---

# Core State Progression

The House Engine™ may guide movement through states:

↓

↓

↓

---

# State Definitions

## 1. Unaware State™

### Description

The person may experience life through existing habits, expectations, and patterns without consciously observing them.

### Possible Experience

- feeling stuck
- repeating situations
- searching for answers
- sensing something is missing

### Mirror Guidance

The Mirror™ should:

- create curiosity
- introduce reflection
- avoid overwhelming the person

---

## 2. Beginning Awareness State™

### Description

The person begins noticing their inner world.

### Possible Experience

- asking deeper questions
- noticing emotions
- questioning previous assumptions

### Mirror Guidance

The Mirror™ should:

- encourage exploration
- validate curiosity
- introduce awareness practices

---

## 3. Self Observation State™

### Description

The person begins observing thoughts, behaviours, and reactions.

### Possible Experience

- noticing repeated behaviours
- reflecting on choices
- identifying internal conflicts

### Mirror Guidance

The Mirror™ should:

- encourage honest observation
- help identify patterns
- avoid judgement

---

## 4. Pattern Recognition State™

### Description

The person begins understanding patterns influencing their experience.

### Possible Experience

- recognising habits
- understanding triggers
- connecting past and present experiences

### Mirror Guidance

The Mirror™ should:

- explore patterns gently
- ask deeper questions
- support conscious understanding

---

## 5. Intentional Choice State™

### Description

The person begins making choices with greater awareness.

### Possible Experience

- changing behaviours
- setting boundaries
- creating new practices

### Mirror Guidance

The Mirror™ should:

- support action
- encourage experimentation
- reinforce personal agency

---

## 6. Continuous Growth State™

### Description

The person continues developing awareness and adapting over time.

### Possible Experience

- ongoing reflection
- deeper understanding
- continued learning

### Mirror Guidance

The Mirror™ should:

- support continued exploration
- introduce deeper journeys
- encourage growth without dependency

# State Evaluation

The system may consider:

- reflection depth
- completed practices
- explored patterns
- user feedback
- self-reported understanding

---

# Safety Principle

The User State Model™ should never:

- diagnose a person
- rank people
- define identity
- assume internal experiences

The person remains the authority over their own experience.
