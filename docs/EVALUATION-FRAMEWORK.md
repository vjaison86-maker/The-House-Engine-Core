# Evaluation Framework™

## Status

Version: 0.1

Stage: Foundation

---

# Purpose

The Evaluation Framework™ defines how The House Engine™ measures quality, usefulness, and impact.

The purpose is not to judge a person's transformation.

The purpose is to evaluate whether the system is creating meaningful opportunities for awareness, reflection, and growth.

---

# Core Principle

## Improvement Through Learning

The House Engine™ should continuously learn from:

- user experiences
- reflection outcomes
- feedback
- research
- experiments

A component is not considered complete because it exists.

It improves through interaction.

---

# Evaluation Philosophy

The House Engine™ evaluates:

## The Experience

Did the person engage with the process?

## The Understanding

Did the person gain new awareness?

## The Practice

Did the person have an opportunity to apply insight?

## The Journey

Did the system provide a meaningful next step?

# Component Evaluation

## Room Evaluation

Purpose:

Evaluate whether a room creates the intended experience.

Questions:

- Is the purpose clear?
- Does the room create awareness?
- Does it guide the person naturally?
- Does it connect to other layers?

---

## Pattern Evaluation

Purpose:

Evaluate whether a pattern helps explain human experience.

Questions:

- Is the pattern clearly defined?
- Does it avoid judgement?
- Does it create recognition?
- Can a person explore it safely?

---

## Question Evaluation

Purpose:

Evaluate whether questions create meaningful reflection.

Questions should be:

- open-ended
- curiosity-driven
- non-leading
- personally relevant

Evaluation questions:

- Did the question create reflection?
- Did it reveal something useful?
- Did it encourage deeper exploration?

---

## Practice Evaluation

Purpose:

Evaluate whether practices convert awareness into action.

Questions:

- Is the practice clear?
- Is it realistic?
- Can someone complete it?
- Does it create learning?

---

## Journey Evaluation

Purpose:

Evaluate whether journeys guide meaningful progression.

Questions:

- Is the progression understandable?
- Does each step have purpose?
- Does it respect personal pace?
- Does it create movement?

---

## Mirror Evaluation

Purpose:

Evaluate the quality of AI guidance.

The Mirror™ should be evaluated on:

### Reflection Quality

Does it help people think deeper?

### Question Quality

Does it ask meaningful questions?

### Respect

Does it maintain personal agency?

### Alignment

Does it follow The House Engine™ principles?

---

# Product Evaluation

Products should be evaluated through:

## Value

Does the product solve a meaningful need?

## Experience

Is it simple and engaging?

## Transformation

Does it create movement or insight?

## Feedback

What do users learn from using it?

---

# Feedback System

The House Engine™ should collect:

## User Feedback

Examples:

- What was helpful?
- What was unclear?
- What changed after using it?

---

## Behaviour Feedback

Examples:

- Did the person return?
- Did they complete practices?
- Did they explore further?

---

## System Feedback

Examples:

- Which questions create deeper reflection?
- Which practices are most useful?
- Which journeys need improvement?

---

# Evaluation Standards

The House Engine™ should avoid:

- measuring people as success or failure
- forcing transformation timelines
- creating dependency on the system

The goal is:

Awareness → Understanding → Choice
