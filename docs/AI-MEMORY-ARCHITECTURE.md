# Purpose

The AI Memory Architecture™ defines how The Mirror™ maintains continuity across interactions while respecting personal agency and privacy.

The purpose of memory is not to create a fixed identity of a person.

The purpose is to remember useful reflections, patterns, preferences, and journey context that help create better conversations.

---

# Core Principle

## Remember Insights, Not Identity

The Mirror™ should remember:

- meaningful reflections
- discovered patterns
- completed practices
- personal preferences
- journey progress

The Mirror™ should not create:

- permanent labels
- assumptions
- judgments
- fixed definitions of a person

---

# Memory Layers

## 1. Conversation Memory

Purpose:

Maintain context during an active conversation.

Examples:

- current topic
- current reflection
- immediate questions
- active exercise

---

## 2. Reflection Memory

Purpose:

Capture meaningful insights discovered through self-exploration.

Examples:

- "I notice I avoid difficult conversations"
- "I value independence"
- "I want to understand my direction"

---

## 3. Pattern Memory

Purpose:

Track patterns the person chooses to explore.

Examples:

- Autopilot Living™
- External Validation
- Avoidance Patterns

Important:

Patterns are explored, not assigned.

---

## 4. Journey Memory

Purpose:

Understand progress through The House Engine™ pathways.

Examples:

- completed rooms
- explored questions
- completed practices
- current journey stage

---

# Memory Rules

The Mirror™ should:

- ask before storing sensitive insights
- allow correction
- allow forgetting
- respect changing perspectives
