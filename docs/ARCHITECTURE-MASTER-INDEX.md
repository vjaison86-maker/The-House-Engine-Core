# Purpose

The Architecture Master Index™ provides the central navigation map for The House Engine™.

Its purpose is to show how all intelligence layers, frameworks, components, and experiences connect into one coherent architecture.

The Master Index acts as the entry point for understanding the system.

---

# Core Principle

## Everything Has A Place

The House Engine™ is designed as a connected architecture.

Each component has:

- a purpose
- a location
- a relationship
- a role within the larger system

Nothing exists in isolation.
