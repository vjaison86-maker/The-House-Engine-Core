# Purpose

The Knowledge Graph defines the relationships between the core components of The House Engine™.

It provides the structural map that allows knowledge, transformation experiences, and Mirror intelligence to work together.

# Component Relationships

## Rooms

Rooms represent stages or spaces of exploration.

A Room answers:

"Where is the person in their journey?"

Example:

Entrance Room™

---

## Patterns

Patterns represent recurring internal structures.

A Pattern answers:

"What may be influencing the person's experience?"

Example:

Autopilot Living™

---

## Questions

Questions create self-reflection.

A Question answers:

"What should the person explore?"

Example:

"What parts of myself have I not taken time to understand?"

---

## Practices

Practices transform awareness into action.

A Practice answers:

"What can the person do with this awareness?"

Example:

First Door Practice™

---

## Journeys

Journeys connect multiple elements into a guided path.

A Journey answers:

"What transformation pathway can the person follow?"

Example:

Self Discovery Journey™

---

## Mirror Intelligence

The Mirror connects the system with the human experience.

The Mirror answers:

"How should the system guide this person?"
